## TURN 02.01 — Make task deletes slot-based and create_new_turn failure-safe

### Notes

1. [REF 01.02.note.02] create_new_turn now applies title, note and task operations once, to a prepared copy of the turn, before any file is written. fill_turn copies the net file updates from the active turn into that copy instead of re-running the operations, so a note or task error can no longer appear after write_files has changed disk. If a step still fails (an I/O error in write_files or when saving), rollback_active_files restores every file in active_baseline, drops the turn's .deleted records, and the new turn is discarded (a reused empty turn is reset to empty).

2. Limit of the rollback: write_files records active_baseline only after Overlay::commit succeeds. If commit fails halfway, some files are already written but have no baseline, so neither rollback nor later net-diff computation sees their original content. Recording the baseline before commit would close this.
